B.Tech Academic Project

Student Academic Performance Prediction and AI-Based Analysis Using Machine Learning

A web application that predicts whether a student's academic performance is Low, Medium or High from attendance, marks and study habits, then explains the result and suggests personalised, prioritised steps for improvement.

Login Student Registration About

System overview

EduPredict stores student academic records, trains three machine-learning classifiers (Decision Tree, Logistic Regression and Random Forest), picks the best one using cross-validation, and uses it to predict a performance category for each student. A transparent rule-based engine then turns the student's weak factors into practical recommendations.

Teachers get a dashboard with class-wide statistics; students get a clear breakdown of where to improve.

Main objectives

  • Predict performance category (Low / Medium / High) using machine learning.
  • Help students see their academic weaknesses early.
  • Give teachers statistics and visualisations of class performance.
  • Provide explainable, personalised recommendations that work offline.
  • Compare algorithms with standard evaluation metrics.
